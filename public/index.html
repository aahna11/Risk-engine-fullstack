Methodology

Formulas

ATR (Wilder): TR = max(H-L, |H-prevC|, |L-prevC|); first ATR = mean of first n TR; ATR = (prev x (n-1) + TR) / n. Stop = entry -/+ multiplier x ATR.

Fixed-fractional size: (equity x risk%) / |entry - stop|.

Kelly: p - (1-p)/b, b = average win / average loss. Full Kelly is very volatile; use half or quarter Kelly.

Historical VaR: percentile of close-to-close returns applied to equity. It is not a maximum loss.

Kill switch: UTC day P&L of simulated trades; triggers at P&L <= -(equity x limit%); blocks new simulated trades on the server. It cannot cancel real broker orders.

CSV format

Header date,open,high,low,close, dates YYYY-MM-DD, at least 20 valid rows, max ~5 MB.
